# A Journey to Highland Vaults

**A Journey to Highland Vaults** es un juego endless donde el jugador controla a un arquero en un mundo generado de manera procedural. Cada partida es única, ya que las salas se generan aleatoriamente, al estilo de *The Binding of Isaac*.

## Características

- **Generación Procedural**: Cada sala es diferente en cada partida.
- **Acción y Supervivencia**: Enfréntate a enemigos en cada sala y sobrevive.
- **Power-ups**: Mejora tus habilidades con power-ups y pociones.
- **Dificultad Progresiva**: Cada sala presenta nuevos desafíos.

## Power-ups Disponibles

1. **Velocidad de Disparo**: Aumenta la cadencia de tus disparos.
2. **Disparo Triple**: Dispara tres flechas a la vez.
3. **Más Daño**: Aumenta el daño de tus ataques.

Además, podrás encontrar **pociones de salud y escudos** para mejorar tu resistencia.

## Jugabilidad

- **Movimiento**: `W, A, S, D` para moverte.
- **Disparo**: `Click izquierdo` del ratón.
- **Minimapa**: `Tab` para visualizarlo.
- **Interacción con el entorno**: Algunas cajas pueden romperse y soltar recompensas.

## Tipos de Enemigos

Existen **tres tipos de enemigos** con distintos patrones de ataque. Para avanzar a la siguiente sala, deberás eliminarlos.

## Instalación

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/agascocompte/a-journey-to-highland-vaults.git
   cd a-journey-to-highland-vaults
   ```

2. **Abrir con Unity**:
   - Asegúrate de tener [Unity](https://unity.com/) instalado.
   - Abre el proyecto desde el Hub de Unity o directamente desde el Editor.

3. **Compilar el Juego**:
   - En el Editor de Unity, ve a `File` > `Build Settings`.
   - Selecciona tu plataforma de destino (Windows, macOS, etc.).
   - Haz clic en `Build` y elige una ubicación para guardar los archivos compilados.

4. **Ejecutar el Juego**:
   - Navega a la carpeta donde compilaste el juego.
   - Ejecuta el archivo correspondiente a tu plataforma (`.exe` en Windows, `.app` en macOS).
